# Prototipo visual PyOreX v2 (referencia de diseño)

No es la aplicación: es el prototipo interactivo con datos simulados que el usuario aprobó como lenguaje visual (cinta, ventanas flotantes, paneles contextuales, selección enlazada, galerías de diagramas, secciones y mapas).

- Verlo: abrir `pyorex-v2.html` en el navegador (archivo único, sin servidor).
- Código: `src/` (React 18 + Zustand + SVG propio). `npm i && npm run dev` dentro de esta carpeta.
- Está fuera del workspace pnpm del repo (no figura en `pnpm-workspace.yaml`): no afecta builds ni tests de la app.
- Guía para continuar: `../CONTINUAR_PYOREX.md`.
